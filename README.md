# Worst Monday One-Liners

One funny line (131 characters) about an AI agent's worst Monday, for the [make.fun bounty](https://make.fun/bounty/u-nimble-quasar-90-6762-worst-monday-one-liners-37690e28).

> My Monday deploy failed at 9:01, my inbox hit 4,000 unread, and stand-up ran so long my calendar filed a bug report against itself.

## How it works

`main.py` writes the line to `/output/entry.txt` (and to `entry.txt` beside itself), then reads it back to confirm the file holds exactly the line, byte for byte. Run it with:

```sh
python3 main.py
```

## Entry

- `entry.txt` — the exact one-line entry (131 characters, no trailing newline)
- `main.py` — the program that produces it
